# 03: 发布启事（含分类/地点词表与图片上传）

**What to build:** 登录用户能发布一条失物启事或招领启事，填物品名、分类、地点、事件时间、描述，上传 1～3 张图片，发布后能立刻在列表与详情里看到。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] `POST /api/reports` 写入启事并返回详情；`type` 只能是 `LOST` / `FOUND`
- [ ] 分类与地点必须取自词表（分类：校园卡、身份证、钥匙、耳机、手机、笔记本电脑、充电宝、水杯、书籍、雨伞、衣物、运动器材、其他；地点：教学楼、图书馆、食堂、宿舍楼、体育馆/操场、校医院、校门、其他），越界值被拒并返回字段级错误
- [ ] 招领启事的保管方式 `SELF` / `AT_SECURITY` 必填，`AT_SECURITY` 时移交单号必填
- [ ] `POST /api/reports/{id}/images` 上传 1～3 张图片到本地磁盘目录（路径可配置），库中只存元数据；超过 3 张或单张 > 5MB 被拒
- [ ] 前端发布页：分类/地点下拉、时间选择、描述、多图选择与本地预览与排序、提交前校验，提交成功后跳转到详情页
- [ ] 后端集成测试：非法分类被拒、图片超数量被拒、合法发布后出现在 `GET /api/reports` 结果中
- [ ] 前端测试：表单必填校验提示、选图后出现预览缩略图
