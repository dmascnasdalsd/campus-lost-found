# 05: 启事生命周期——编辑、删除、标记归还/移交

**What to build:** 发布者能在发布后 30 分钟内修改或删除自己的启事；能把自己的启事标记为已归还或已移交（交保卫处）；越权与超时都被明确拒绝。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] `PATCH /api/reports/{id}` 修改启事，仅发布者或管理员可操作，仅允许在发布后 30 分钟内（超时返回可辨识错误码）
- [ ] `DELETE /api/reports/{id}` 删除启事，同上权限与时间窗
- [ ] `PUT /api/reports/{id}/status` 支持 `RETURNED`（已归还）与 `HANDED_OVER`（已移交，招领启事专用，必须带移交单号）
- [ ] 非发布者、非管理员调用以上接口一律返回越权错误码
- [ ] 前端「我的发布」页面：列出自己的全部启事与实时状态徽标，提供编辑、删除、标记归还 / 移交操作，并显示 30 分钟编辑窗口剩余情况
- [ ] 后端集成测试：越权编辑被拒、超时编辑被拒、标记归还需要确认、标记已归还在默认列表中消失
- [ ] 前端测试：「我的发布」渲染不同状态徽标与对应可操作按钮
